# Grove v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Rust binary `grove` that runs a tmux dashboard of Claude Code sessions per project, tracks each session's state via Claude Code hooks, and exposes projects + wiki over MCP.

**Architecture:** One binary, four modes (`grove`, `grove dashboard`, `grove hook`, `grove mcp`, plus `grove add`) sharing plain files under `$GROVE_HOME` (default `~/.grove`). `store.rs` is the only module that writes to disk; `state.rs` is a pure transition function; `tmux.rs` wraps the tmux CLI with a socket parameter.

**Tech Stack:** Rust 2024 (cargo 1.95), ratatui 0.30 + crossterm, rmcp 3.x (`server`, stdio), tokio, serde/serde_json/toml, uuid, notify, clap, anyhow, chrono, tempfile (dev).

**Spec:** `docs/superpowers/specs/2026-10-06-grove-v1-design.md`

> **Execution note:** The user approved the spec and asked Claude to build v1 directly ("you know what's up"). This plan is therefore executed natively in-session; it fixes task order, interfaces and required tests rather than pre-writing every line of code.

## Global Constraints

- Every launched Claude session gets `CLAUDE_CONFIG_DIR=<expanded claude_config_dir>` (default `~/.claude-play`) via `tmux new-window -e`; if the dir doesn't exist, refuse to launch. Never fall back to `~/.claude`.
- Never write to any `~/.claude*/settings.json` or register MCP servers globally; hooks via `--settings run/hooks.json`, MCP via `--mcp-config run/mcp.json`.
- `grove hook` always exits 0 and never blocks; errors go to `$GROVE_HOME/grove.log`.
- All file writes atomic (tmp in same dir + rename), only through `store.rs`.
- tmux ≥ 3.2 required. Grove's tmux config only applies to the `grove` session/server.
- `GROVE_HOME` env overrides `~/.grove` (tests always set it).
- Session files carry `host = "local"`.

## Review Focus

1. **Paths with spaces** (project path, grove binary path, GROVE_HOME) — launch command and generated JSON must quote/exec-form correctly. Test in Task 5.
2. **Slug collisions** — adding "My App" when "my-app" exists must error, not overwrite. Test in Task 2.
3. **Garbage / unknown hook input** — empty stdin, invalid JSON, unknown `session_id`, unknown event → no file change, exit 0. Test in Task 4.
4. **First run with empty/missing `~/.grove`** — dashboard, MCP `list_projects`, and hook must all work with no dirs yet. Tests in Tasks 2, 4, 6.
5. **Project dir deleted after registration** — launching must show an error, not spawn a window in `$HOME`. Test in Task 5.

### Task 1: Scaffold + config

**Files:** Create `Cargo.toml`, `src/main.rs`, `src/config.rs`, `.gitignore`.

**Produces:**
- `struct Config { claude_config_dir: String, tmux_session: String, editor: String, claude_args: Vec<String> }` with `Default`.
- `struct Paths { home, projects, wiki, sessions, run, log }` + `Paths::from_env() -> Paths` (GROVE_HOME or `~/.grove`), `Paths::ensure() -> Result<()>`.
- `fn load_config(&Paths) -> Result<Config>` (missing file → defaults).
- `fn expand_tilde(&str) -> PathBuf`.
- `fn claude_dir(&Config) -> Result<PathBuf>` (expanded; error if missing).
- `fn editor(&Config) -> String` (config → $EDITOR → `vi`).

**Tests:** defaults when no file; partial file merges with defaults; tilde expansion; `claude_dir` errors for missing dir; GROVE_HOME respected.

- [ ] Write tests → fail → implement → pass → commit `feat: scaffold crate and config`.

### Task 2: Store (projects, sessions, wiki)

**Files:** Create `src/store.rs`, `src/model.rs`.

**Produces (`model.rs`):**
- `struct Project { name, path: PathBuf, color: Option<String>, summary: Option<String> }` (+ `slug()`).
- `enum State { Starting, Working, NeedsYou, YourTurn, Ended }` serialized snake_case.
- `struct Session { id, project, name, host, tmux_window: Option<String>, state, message: Option<String>, created_at, updated_at }`.
- `fn slugify(&str) -> String`.

**Produces (`store.rs`, `struct Store { paths: Paths }`):**
- `write_atomic(path, bytes)`.
- `list_projects() -> Vec<Result<Project, (PathBuf, String)>>` (bad files reported, not fatal); `get_project(name_or_slug) -> Result<Project>`; `add_project(Project) -> Result<()>` (errors on slug collision); `save_project(&Project)`.
- `list_sessions(project: Option<&str>) -> Vec<Session>`; `get_session(id) -> Option<Session>`; `save_session(&Session)`; `delete_session(id)`.
- `wiki_sections(slug) -> Vec<(String /*title*/, PathBuf)>`; `read_wiki(slug, section: Option<&str>) -> Result<String>`; `write_wiki(slug, title, content) -> Result<PathBuf>` (file = slugified title; content starts with `# title`).

**Tests:** atomic write leaves no tmp; add/get/list roundtrip; **slug collision errors**; malformed TOML shows as Err entry; session save/list/filter; wiki write then list titles + read one + read all; **all list ops on empty/missing dirs return empty**.

- [ ] Tests → fail → implement → pass → commit `feat: file store for projects, sessions, wiki`.

### Task 5: tmux wrapper, launcher, generated run files

**Files:** Create `src/tmux.rs`, `src/launch.rs`, `src/runfiles.rs`.

**Produces:**

- `launch::LaunchSpec { window_name, cwd, env, argv }`; `launch::build(cfg, paths, project, session_id, name) -> Result<LaunchSpec>` (checks claude dir + project dir exist); `launch::start(&Tmux, &Store, cfg, project, name: Option<String>) -> Result<Session>` (writes `starting` session, creates window, records window id); `next_session_name(store, slug) -> String` (`s1`, `s2`, …).

**Tests:** `build` sets `CLAUDE_CONFIG_DIR` to expanded dir and includes `--session-id/--settings/--mcp-config/-n`; **missing claude dir → Err; missing project dir → Err**; generated hooks.json parses and every handler uses `args: ["hook"]` with absolute command; **GROVE_HOME containing a space** produces valid JSON paths; tmux integration on `-L grove-test-<pid>`: new session, new_window with env (verify via `show-environment`/`display -p`), list, kill; next_session_name increments.
